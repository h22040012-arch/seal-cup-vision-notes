# 公开范围

按项目所有者要求公开实际高低压 ONNX 权重、C++ 推理源码、C# 接入脚本、真实工件示例图和实际推理参数，并增加 Python 命令行入口。

去除项目使用方的公司、客户和人员名称、用户名及本机训练路径。模型元数据删除 description 和 date 两项，其余字段、图结构和权重原样保留。第三方作者、产品名与许可证署名保留。公开模型摘要因此变化，profiles.ini 更新为公开文件的摘要。

不复制原工作目录历史，不包含凭据、个人联系方式、原始工作报告、厂商 SDK 或完整生产设备工程。真实图片使用 front/back/empty 中性文件名，不附带原始采集文件名和现场路径。

后续提交继续检查文本、图片可见内容和模型元数据中的名称，不能仅依赖 .gitignore。
