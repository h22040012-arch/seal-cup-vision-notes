# 皮碗方向 ONNX 模型

高、低压两份 YOLO26n 检测模型。原导出元数据记录 Ultralytics 8.4.178。高压类别 hp_front/hp_back，低压 lp_front/lp_back。两份模型分别训练，输入契约不同，不能互换预处理。

公开版本从实际使用的 ONNX 复制，仅移除顶层 metadata_props 中包含训练路径的 description 及训练日期 date。清理脚本逐字节确认 GraphProto 未变，权重数值、计算图、算子、输入输出和类别映射均未变。用相同输入对原文件和公开文件的输出做逐元素对比。

固定输入原图为 4024×3036。高压外部裁剪 ROI [2200,1000,3000,2750] 后输入 640 方图；低压全图输入，图内含 ROI [1750,850,2600,2550] 与 960 方图预处理。

低压示例取自既有训练/验证材料。六张图仅覆盖基本方向和未检出，不是独立测试集，不支持总体准确率或产线性能声明。置信度不是经过校准的缺陷概率。
